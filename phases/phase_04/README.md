## 📖 Overview

This directory defines **Phase 4** of the course progression. Phases act as high-level chronological and thematic wrappers that group multiple weekly modules together based on major pedagogical milestones (e.g., the OSEMN framework transitions). 

This phase specifically focuses on scalable production infrastructure using AWS Deadline Cloud render farms, color space theory/management (ACES/CIELAB), and foundational data and information visualization algorithms.

> **⚠️ Phase Routing Notice**
> This directory acts primarily as an organizational wrapper. Ensure that granular lecture assets, code snippets, and weekly materials are placed within their respective `module_XX/` subdirectories, rather than loosely at the root of the phase directory.
