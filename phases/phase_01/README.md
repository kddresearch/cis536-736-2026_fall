## 📖 Overview

This directory defines **Phase 1** of the course progression. Phases act as high-level chronological and thematic wrappers that group multiple weekly modules together based on major pedagogical milestones (e.g., the OSEMN framework transitions). 

This phase specifically focuses on establishing core toolchain bring-up, foundational graphics linear algebra, 3D viewing and projection transformations, and OpenUSD scene graph representations.

> **⚠️ Phase Routing Notice**
> This directory acts primarily as an organizational wrapper. Ensure that granular lecture assets, code snippets, and weekly materials are placed within their respective `module_XX/` subdirectories, rather than loosely at the root of the phase directory.

<hr>

## 🗂️ Phase Structure (Included Modules)

| Module Directory | Topic / Description |
| :--- | :--- |
| [`module_00/`](../../modules/module_00/) | **Welcome & Course Overview:** Course logistics, syllabus walkthrough, software requirements, and introduction to modern real-time graphics pipelines. |
| [`module_01/`](../../modules/module_01/) | **Toolchain Bring-Up & Math Foundations:** Environment setup (Blender, OpenUSD, Python/C++ toolchains) and fundamental 3D vector/matrix linear algebra. |
| [`module_02/`](../../modules/module_02/) | **Viewing, Projections & OpenUSD Scene Graphs:** Camera models, perspective/orthographic projections, and hierarchical OpenUSD composition/prims. |
| `README.md` | This phase overview and index. |

## 🦅 Standard Operating Procedures (SOPs)

All instructional staff interacting with this phase directory must adhere to the following protocols:

* **Protocol 1 (Phase Cohesion):** Ensure all modules contained within this phase cleanly map to the overarching phase objective defined in the syllabus taxonomy.
* **Protocol 2 (Navigation):** Maintain cross-links in the module READMEs pointing back to this Phase root to preserve GitOps navigability.
* **Protocol 3 (Milestone Anchoring):** Ensure the terminal module of this phase explicitly prepares the student for the associated major assignment/milestone.
