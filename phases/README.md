## 📖 Overview

This directory acts as the master index for the high-level course progression. **Phases** are conceptual, chronological wrappers that group multiple weekly modules together based on major pedagogical milestones or methodological pillars (e.g., Foundations, Obtain/Scrub, Explore/Model, Evaluate). 

> **⚠️ Parent Directory Routing Notice**
> This directory is strictly for structural routing. All actual course content, scripts, and assignment assets must be placed inside the granular `module_XX/` subdirectories located in the `modules/` repository root.

<hr>

## 🗂️ Phase Directory Structure

| Phase Directory | Pedagogical Objective & Modules |
| :--- | :--- |
| [`phase_01/`](phase_01/) | **Foundations:** Modules 0–2 (Welcome & Course Overview; Toolchain Bring-Up & Math Foundations; Viewing, Projections & OpenUSD Scene Graphs) |
| [`phase_02/`](phase_02/) | **Core Mechanisms:** Modules 3–5 (PBR Lighting & Real-Time RT/GI; Shader Graph & Procedural Textures; Procedural Modeling: Geometry Nodes) |

| [`phase_04/`](phase_04/) | **Integration & Application:** Modules 9–10 (Cloud Render Farms: AWS Deadline Cloud; Color; Data & Info Visualization I) |
| [`phase_05/`](phase_05/) | **Future & Capstone:** Modules 11–13 (Visualization II & Special Topics; Cross-Pillar Integration & Final Prep; Project Presentations) |
