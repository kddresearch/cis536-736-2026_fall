Module 02: Search & Optimization

Navigating State Spaces, From BFS to A*

Introduction

Welcome to the foundation of Artificial Intelligence. Before we can have agents that "learn" (Machine Learning), we need agents that can "plan." In this module, we treat problem-solving as search: finding a sequence of actions that leads from a start state to a goal state.

We will cover the classics (BFS, DFS) and move quickly to the algorithms that still power modern systems like GPS navigation and game pathfinding (A*).

Learning Objectives

  • Formalize a real-world problem as a State Space Graph (States, Actions, Transitions).
  • Implement Uninformed Search strategies (BFS, DFS, IDS) and analyze their complexity.
  • Apply Heuristic Search (A*) and define admissibility and consistency.
  • Differentiate between Tree Search (forgetful) and Graph Search (memorable).
